# 🌤️ Clima App

Uma aplicação web de previsão do tempo desenvolvida com HTML, CSS e JavaScript, criada para praticar conceitos de desenvolvimento web, consumo de APIs, lógica de programação e interação com a interface.

## 🚀 Demonstração

👉 Clique aqui para acessar o Clima App

## ✨ Funcionalidades

🔎 Pesquisa de cidades  
🌡️ Temperatura atual  
🌡️ Sensação térmica  
💧 Umidade do ar  
💨 Velocidade do vento  
☀️ Identificação entre dia e noite  
🌙 Alteração do fundo conforme o período  
🌧️ Descrição das condições climáticas  
⚠️ Mensagem de erro para cidades não encontradas  
📱 Interface responsiva  

## 🛠️ Tecnologias utilizadas

HTML5  
CSS3  
JavaScript  
API Open-Meteo  
Fetch API  

## 📚 Objetivo

Este projeto foi desenvolvido para colocar em prática conhecimentos de HTML, CSS e JavaScript, trabalhando principalmente com consumo de APIs, requisições assíncronas, manipulação do DOM, eventos e criação de uma interface responsiva.
